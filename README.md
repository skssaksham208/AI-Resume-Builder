# AI Resume Builder

An AI-powered Resume Builder that generates ATS-friendly professional resumes using Google Gemini API.

## Features

* Generate professional resumes using AI
* ATS-friendly resume formatting
* Resume preview in real-time
* Download resume as PDF
* Copy generated HTML
* Responsive modern UI
* Multiple resume categories

## Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)
* Google Gemini API

## How It Works

1. Enter your Gemini API Key
2. Fill in personal details, education, experience, projects, and skills
3. Click **Generate Resume with AI**
4. Review the generated resume
5. Download or copy the resume
